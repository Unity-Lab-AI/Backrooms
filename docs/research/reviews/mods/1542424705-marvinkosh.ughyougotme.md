# RimWorld mod review: Ugh You Got Me

- Steam Workshop ID: `1542424705`; [publisher page](https://steamcommunity.com/sharedfiles/filedetails/?id=1542424705), [change notes](https://steamcommunity.com/sharedfiles/filedetails/changelog/1542424705), and [publisher comments](https://steamcommunity.com/sharedfiles/filedetails/comments/1542424705).
- Profile row 237; local package ID `marvinkosh.ughyougotme`. The Workshop page displays RemingtonRyder as creator; the sources reviewed do not explain the difference in naming.
- Checked 2026-09-27. Publisher page lists version 1.0.7, RimWorld 1.0–1.6, and an update on 2025-06-21. The local metadata snapshot lists support 1.0–1.6, no local version, a hard dependency on Harmony, and load-after Harmony. The pinned local game is RimWorld `1.6.4871 rev590`.

## Publisher-described behavior

The publisher says social fights can end early when a pawn is badly hurt or in significant pain. Masochists ignore the pain check. Bloodlust pawns can keep fighting until the other pawn gives in, dies or is downed. Romantic partners may stop based on an opinion threshold; some fights may be prevented if they would end immediately; a missing body part that is still bleeding is also a stop condition.

The latest change note says the mod was compiled against RimWorld 1.6 unstable and its load folders were updated. Earlier notes include game-version folder recompiles and a change from a maximum-HP check to a health threshold. Publisher comments say the checks run during social fights rather than every tick, describe adding/removing the mod from an existing save as safe, and discuss surrender thresholds and high-damage instant kills. These are publisher statements, not reproduced results.

Steam currently shows a Community Guidelines removal banner and a generic “incompatible with RimWorld” notice. The reason for removal and the reason behind the incompatibility banner are not specified. Current Workshop download availability was not tested. Do not treat either banner as a reproduced RWT or game-compatibility result.

## Rights and integration boundary

No publisher-linked source repository or license was found. The Workshop page asks users to contact the author before re-uploading; that is a permission request, not a general license. Do not copy or bundle its code or assets. No public integration API is established by the sources reviewed.
