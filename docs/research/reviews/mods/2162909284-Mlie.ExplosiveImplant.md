# RimWorld mod review: Explosive Implant (Continued)

- Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=2162909284
- Row 89; local package `Mlie.ExplosiveImplant`; local version `1.6.1`; support declaration 1.0–1.6.
- Local metadata requires and loads after Harmony. Exact source repository and license were not verified. The Workshop page describes the mod as still in development and recommends keeping a pre-install save.
- Reviewed 2026-09-27. No runtime test was run.

## Source facts

The publisher describes a player-triggered brain implant crafted at a fabrication bench after Bionics, an advanced version with twice the blast radius, and a knockout implant. The page says corpses may be detonated and an implanted slave creates a terror effect. A Workshop user comment reports faction-crossing detonation control; it is an unverified lead, not a confirmed feature.

## Rimrooms use

- **Provisional disposition:** optional pawn/threat content; no Rimrooms containment dependency.
- **Feature mapping:** `RR-STA; RR-THREAT; RR-EVD; RR-COMPAT`.
- Check install/removal, detonation authority by faction and co-op client, blast size, knockout effects, corpse/evidence loss, and saved state. Do not base Rimrooms threat control or specimen disposition on it.

## Evidence status

No gameplay or RWT test was run. Publisher claims and the faction-crossing comment are not reproduced behavior.
