## Verified source facts

- It previews a generated map for a selected world tile, offers optional per-tile seed rerolling, and describes a separate preview generator for RimWorld 1.6 intended to account for map-feature mods.
- Local license files specify CC BY-NC-SA 4.0 for code, assemblies, and other files unless an individual file says otherwise. Do not copy its implementation or assets into Rimrooms.
- The preview concerns ordinary world tiles; it does not supply a procedural Backrooms-room preview or persistent coordinate identity.
