## Verified source facts

- The mod shows progress and elapsed time during startup and several long in-game operations, including map generation and save loading. It also has an optional report on mod loading time.
- The Workshop page says it patches early initialization code and describes a setting that can disable that patching to troubleshoot conflicts.
- It improves the user's existing loading experience; it does not add campaign content. No Rimrooms patch or dependency is planned.
