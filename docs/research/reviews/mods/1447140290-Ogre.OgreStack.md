## Source facts and Rimrooms use

The publisher describes custom stack sizes per item, using scalar or fixed modes. Its published defaults include a ×30 scalar for Small Volume Resources and a fixed 1,000 stack for Resources. The local Core Silver ThingDef has a base stack limit of 500 and the `smallVolume` flag, so the published default-setting estimate is 15,000 silver per stack. With that setting, one million silver is 67 stacks; under Core-only it is 2,000. These are calculated expectations, not a readout of the current save's effective stack limit; an in-game configuration or individual-item override can change them. The author says to save after changing limits because a change followed by reload without saving could lose items. The author suggests moving it last if load-order problems appear; this is not a tested ordering instruction.

**Provisional disposition:** optional stack-size configuration; it is active in the selected 294-mod profile (row 157, package `Ogre.OgreStack`). Cross-reference the [economy and logistics model](../../../CAMPAIGN_ECONOMY_MODEL.md), [v0.2 workbook](../../../../outputs/4b7976f0-1820-4ffa-a191-bf7c7f79b010/Rimrooms_Campaign_Economy_v0.2.xlsx), and [profile interaction map](../../PRIORITY_PROFILE_INTERACTIONS.md#stack-size-cargo-and-shared-item-exchange-row-157--rows-122259--rwt). Rimrooms cargo, dossiers, prices, and trade transfers must work with both the profile's effective stack settings and vanilla limits. Related features: `RR-FAC`, `RR-ECO`, `RR-EVD`, `RR-EXP`, `RR-OUT`, `RR-MP`, `RR-COMPAT`.
