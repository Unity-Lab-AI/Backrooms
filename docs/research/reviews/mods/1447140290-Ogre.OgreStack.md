## Source facts and Rimrooms use

The publisher describes custom stack sizes per item, using scalar or fixed modes. Changes apply without reload, but the author says to save after changing stack limits because a change followed by reload without saving could lose items. The author suggests moving it last if load-order problems appear; this is not a tested ordering instruction.

**Provisional disposition:** optional stack-size configuration; Rimrooms cargo, dossiers, prices, and trade transfers must also work with vanilla stack limits. Related features: `RR-FAC`, `RR-ECO`, `RR-EVD`, `RR-EXP`, `RR-OUT`, `RR-MP`, `RR-COMPAT`.
