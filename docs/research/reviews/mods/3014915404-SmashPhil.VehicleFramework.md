## Verified source facts

- This is a modder framework for creating vehicles; it does not add vehicles on its own.
- Its published description covers vehicle movement, component health, customization, and launch systems. The specific public APIs are not part of this first-pass review.
- The local package supports 1.6 and requires Harmony. Its `LoadFolders.xml` points to absent local folders `1.4/_Biotech` and `1.6/Compatibility/Anomaly`. The public 1.6 upstream tree contains several compatibility subfolders but no Anomaly subfolder; the missing local path may represent an optional patch gap, not a framework startup failure.
- The current publisher page shows tags through 1.6. The Workshop page also displays a Community removal notice; the notice gives no further reason, so this review does not infer one.
- No Vehicle Framework code or assets are copied into Rimrooms.

## Rimrooms integration decision

- **Provisional disposition:** optional profile framework; no direct Rimrooms dependency. It may be useful for a future vehicle-based expedition or outpost, if that fits the campaign and works with Odyssey, Gravship Expanded, and RWT.
- Leave absent optional compatibility folders untouched unless a source-verified conflict affects a chosen feature. The exact runtime effect of the Anomaly folder reference remains untested.
- Related systems: `RR-OUT`, `RR-SPACEFLIGHT`, `RR-COMPAT`.
- Keep the machine gate as the Backrooms entry point and preserve native gravship systems. Do not add custom vehicles solely because this framework is installed.
- Core-only play must not depend on Vehicle Framework.
