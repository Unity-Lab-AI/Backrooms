## Verified source facts

The publisher describes an action that can calm colonists or prisoners during mental breaks. The Workshop page's listed update date is 2025-07-06 and its version tags cover 1.0–1.6. The page has a historical 2019 “Multiplayer support” note; it is not evidence of support for RimWorld Together. Recent user comments report issues and the author said an update was planned, but those reports were not reproduced and do not change the listed page version. A comment naming “ferny Capture” is about a different package from the selected Capture Them row.

## Rimrooms integration decision

- **Provisional disposition:** optional mental-break aid; do not make it the required staff-crisis or custody system.
- **Feature mapping:** `RR-STA; RR-COMPAT; RR-MP`.
- A pawn calming action is not a company-owned employment, discipline, or visitor system. Keep ordinary mental-break management functional if absent.
- Future check: eligible break types, actor availability, actual mental-state exit versus message-only feedback, cooldowns, wandering, prisoner/guest behavior, save/load, then two-client RWT ownership/synchronization.
