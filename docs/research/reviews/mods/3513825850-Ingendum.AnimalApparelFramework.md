## Source facts and Rimrooms use

The publisher describes an animal-equipment framework with shield belts and jump packs, plus tags and body/render settings used by compatible apparel mods. The page warns it is likely incompatible with the selected `Packs Are Not Belts` mod (row 160), and says Combat Extended is untested. It identifies some compatibility and appearance issues as reports or untested claims. The publisher says this framework is a new implementation; no license was verified, and separately credited armor artwork is not covered by an inferred code license.

**Provisional disposition:** optional framework and animal-equipment reference; no Rimrooms dependency or adapter. Related features: `RR-STA`, `RR-EXP`, `RR-OUT`, `RR-COMPAT`. Do not assume that human security apparel automatically fits animals.
