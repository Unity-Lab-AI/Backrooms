# RimWorld mod review: Adaptive Ideology Storage

- Steam Workshop: [item 3301337278](https://steamcommunity.com/sharedfiles/filedetails/?id=3301337278)
- Review date: 2026-09-27; Workshop page and installed `About.xml` reviewed
- Local package: `Adaptive.Ideology.Storage`; profile row 24; RimWorld 1.4, 1.5, and 1.6 support listed
- Required content: Ideology DLC and Adaptive Storage Framework
- Local test baseline: RimWorld `1.6.4871 rev590`; no runtime test performed

## What it adds

The Workshop description turns selected objects from Ideology into buildable storage and supplies alternate appearances for some pieces. It is an optional way to add storage with an ideological or relic-room look. The page is currently marked removed from the Steam Community and visible only to the viewing account; the module is installed in the local profile.

The page names third-party art/content used in parts of the module and says the publisher does not claim ownership of those materials. Rimrooms must not bundle this mod's files or treat its assets as freely reusable.

## Rimrooms use

When Ideology and this storage module are present, its furniture can inform a distinctive archive, shrine, or ceremonial evidence room. Keep those rooms optional. Rimrooms' Core path still needs ordinary storage and must not require Ideology, Adaptive Storage Framework, or this Workshop item.
