# RimWorld mod review: [Og] Automatic Power Switch

- Steam Workshop: [item 3031634496](https://steamcommunity.com/sharedfiles/filedetails/?id=3031634496)
- Review date: 2026-09-27; Workshop page and installed `About.xml` reviewed
- Local package: `Og.AutomaticPowerSwitch`; profile row 19; `About.xml` lists RimWorld 1.4, 1.5, and 1.6 support, with no declared dependency
- Local test baseline: RimWorld `1.6.4871 rev590`
- Status: source facts recorded; no gameplay or multiplayer test performed

## What it adds

The Workshop description says the player can remotely switch existing vanilla power switches after Microelectronics research. It is meant to make large power grids easier to manage. The publisher warns that it is softly incompatible with Auto Flicker. That named mod is not in the current 294-entry profile.

The page currently reports that the item has been removed from the Steam Community and is only visible to the account viewing it. The mod remains installed in the local selected profile. The page identifies GPLv3 and says some code comes from RT Power Switch; this is not permission to copy it into Rimrooms.

## Rimrooms use

This could support a control-room feel for switching facility zones, but Rimrooms should keep its gate, life-support, and emergency-power controls understandable without it. In the selected profile, record and test the mod's own switch behavior; do not replace or silently automate its controls. For a public Rimrooms setup, account for the Workshop availability issue and keep the feature optional.
