# RimWorld mod review: Adaptive Simple Storage

- Steam Workshop: [item 3297307747](https://steamcommunity.com/sharedfiles/filedetails/?id=3297307747)
- Review date: 2026-09-27; Workshop page and installed `About.xml` reviewed
- Local package: `Adaptive.SimpleStorage`; profile row 26; RimWorld 1.4, 1.5, and 1.6 support listed
- Required mod: Adaptive Storage Framework
- Local test baseline: RimWorld `1.6.4871 rev590`; no runtime test performed

## What it adds

The publisher describes this as an independent port of [JDS] Simple Storage to Adaptive Storage Framework, with reworked storage furniture and appearances. The page describes rotation as a way to change the look of selected pieces. It also documents a major rewrite after which older saves could show missing containers; the page says the stored items should remain safe, but calls out a recovery step. The current Workshop page is marked removed from the Steam Community and visible only to the viewing account; the module is installed in the local profile.

The publisher credits the original mod and states that permission was given for the retextured art. Rimrooms should use the installed behavior as an optional compatibility target and must not copy its assets or code.

## Rimrooms use

Its crates, racks, and cabinets suit organized equipment stores, evidence archives, and shipping rooms. Keep Rimrooms evidence records separate from the storage furniture so items remain findable if a storage module is unavailable. Treat the existing selected profile as a compatibility target, not a mandatory Rimrooms dependency.
