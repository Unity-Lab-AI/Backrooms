## Source facts and Rimrooms use

The publisher says selected humanlike blunt unarmed attacks do 50% damage to buildings instead of the base blunt tool's 150%. The description excludes animals, claws/bites/heat, implant tools, armed melee, and pawn-tantrum item damage. Community discussion about other prisoner escape methods is not evidence that this mod prevents escape.

**Provisional disposition:** optional balance rule only. Related features: `RR-STA`, `RR-THREAT`, `RR-COMPAT`. Do not use it as a custody, containment, or security feature.
