# RimWorld mod review: Adaptive Primitive Storage

- Steam Workshop: [item 3400037215](https://steamcommunity.com/sharedfiles/filedetails/?id=3400037215)
- Review date: 2026-09-27; Workshop page and installed `About.xml` reviewed
- Local package: `Adaptive.PrimitiveStorage`; profile row 25; local metadata lists RimWorld 1.5 and 1.6
- Workshop page lists Adaptive Storage Framework; local metadata additionally lists Harmony
- Local test baseline: RimWorld `1.6.4871 rev590`; no runtime test performed

## What it adds

The publisher describes an independent port of Primitive Storage for Adaptive Storage Framework, with log piles, racks, other primitive-looking containers, and cellars intended to cool perishable food. The page says the cellar effect does not adjust to the surrounding environment normally, so cold conditions and changing temperatures can affect stored food. The current Workshop page is marked removed from the Steam Community and visible only to the viewing account; the module is present in the local profile.

The page credits the original authors and says permission was given for the retextured art used in this port. That permission applies to the port; it is not a license for Rimrooms to copy its files.

## Rimrooms use

The look and storage roles fit supply rooms, rough outposts, kitchens, and sample caches. Treat any food-preservation benefit as unproven for Rimrooms until tested with the selected temperature, hauling, and storage mods. Keep a normal storage path available when the module or framework is absent.
