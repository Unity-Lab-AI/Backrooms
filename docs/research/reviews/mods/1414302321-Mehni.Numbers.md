## Source facts and Rimrooms use

Publisher describes a configurable colonist/prisoner overview with skills, needs, gear, queued jobs, medical/prisoner controls, zone assignment, sorting and saved layouts. It says it can be added to existing saves.

- **Provisional disposition:** optional workforce dashboard; no Rimrooms data ownership.
- **Feature mapping:** `RR-UI; RR-STA; RR-COMPAT`.
- **Checks:** custom Rimrooms work types/columns, medical/prisoner controls, saved layouts, hotkeys, saves; compare with row67 Compact Work Tab (publisher names Numbers as tested, not reproduced here).
- Keep vanilla/Rimrooms Personnel access when absent.

No selected-profile compatibility is established.
