## Source facts and Rimrooms use

Publisher describes architect blueprint resource readouts that count all map resources, changes to blueprint cost display and insufficient-resource messages, and refresh every 204 ticks. It warns the saved MapComponent may error when loading after removal; its recovery steps are save and reload without the mod.

- **Provisional disposition:** optional construction UI convenience; not procurement accounting.
- **Feature mapping:** `RR-FAC; RR-EXP; RR-COMPAT`.
- **Checks:** displayed totals against actual stored resources, blueprint costs, refresh timing, resource/blueprint UI interactions, map transfers, and save/remove/reload. Rimrooms contracts/cargo use owned item data, not this display.

No UI or save behavior was tested.
