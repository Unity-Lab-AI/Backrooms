## Verified source facts

- The original feature shortens the lifetime of liquid filth on permeable terrain; the continuation adds an option to reduce other filth lifetime. Changes apply when filth spawns and do not retroactively alter existing filth.
- Local source contains a Harmony postfix on `Filth.SpawnSetup`, skips respawn-after-load, and exposes XML extensions for terrain and filth settings.
- No license file or reuse statement was found in the inspected page/package. Do not copy its code or assets.

## Rimrooms integration decision

- **Provisional:** configuration-only and optional; consider a narrow XML adapter only if Rimrooms intentionally wants this exact cleanup behavior on custom surfaces.
- Related systems: `RR-SPACE`, `RR-FAC`, `RR-THREAT`, `RR-COMPAT`; see the [feature map](../../../FEATURE_TRACEABILITY.md).
- This affects filth expiration, not terrain or room generation. Generated spaces and their baseline cleanup must work without it.
