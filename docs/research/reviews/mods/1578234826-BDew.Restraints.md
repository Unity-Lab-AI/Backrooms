## Verified source facts

- The publisher describes selecting a pawn and ordering it to restrain or free a target. It lists a steel cost, chance of a standing target fighting back, and mood penalties while restrained and after release.
- The publisher says the 1.6 version has no dependencies and that earlier versions use Harmony/HugsLib. The installed parser snapshot's root dependency does not cleanly express that distinction.
- Steam comments report a possible 1.6 action failure on non-colonist targets. This is an unverified player report.
- No public integration API is advertised. Restraints can alter a pawn's movement and add consequences to custody.

## Rimrooms integration decision

- **Provisional disposition:** use as an optional native restraint tool; no Rimrooms adapter planned.
- Related systems: `RR-STA`, `RR-THREAT`, `RR-COMPAT`.
- Never use restraint as the only way to manage a detainee or threat; retain vanilla bed/prisoner and containment routes.

## Runtime evidence

- Not runtime tested. Confirm the 1.6 dependency interpretation, then test orders against colonists, prisoners, guests, downed pawns, and any Rimrooms captives; check resistance, mood effects, rescue/tending, release, and save/load.
