## Source facts and Rimrooms use

The publisher describes drafted pawns using vanilla AI to seek/attack enemies, with melee/ranged controls, manual overrides, and deactivation when undrafted. It says it can be added to saves and claims broad compatibility. A user report describes pawns repairing gravship structures while active; this is unverified.

- **Provisional disposition:** optional combat automation; authored threat behavior/player control remain independent.
- **Feature mapping:** `RR-THREAT; RR-EXP; RR-STA; RR-COMPAT`.
- **Checks:** draft/undraft, toggles, manual orders, target choice, retreat/containment, AI performance, gravship profile, and RWT separately.

No interaction or performance issue was reproduced.
