## Source facts and Rimrooms use

The publisher describes area expansion/contraction, reordering fixes, unlimited areas and area colors. It says the mod is unnecessary with TD Enhancement Pack, which is not in the selected inventory. The page warns that other selectors remain designed around five areas per type. A Hospitality guest-assignment problem is a user report, not a confirmed defect.

**Provisional disposition:** optional area/UI extension; no Rimrooms dependency. Related features: `RR-FAC`, `RR-OUT`, `RR-UI`, `RR-COMPAT`. The selected Hospitality mods remain a guest-zoning check.

## Runtime follow-up

No runtime test was run. Create more than five areas, test selectors and guest assignment, resizing/display scale, save/load, and map-local zones across outposts. Do not reuse restricted third-party icons/content.
