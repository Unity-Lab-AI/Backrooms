## Publisher-described behavior

The author says this placement patch restores vanilla checks for coolers and vents when used with Replace Stuff. It prevents placing them with blocked intakes/exhausts or overlapping blueprints and requires the over-wall variants to be placed on a wall. The behavior is configurable in mod options. Steam lists Harmony and Replace Stuff Continued as required items, and its page links the original Replace Stuff project as background.

The change notes record the initial release, a 1.5 update, and a 1.6 update that switched references to the Continued version. No public API or exact patch points were verified because the publisher page does not link a source repository.

A user comment reports pawns firing through coolers with this patch plus Replace Stuff Continued and says removing this patch fixed the issue. The author replied that the mod should only alter placement, asked whether vanilla pieces showed the issue, and said they would investigate. This is an unresolved report, not a reproduced conflict. The author also describes conditions for others to continue their mods; that is not a general code or asset license.
