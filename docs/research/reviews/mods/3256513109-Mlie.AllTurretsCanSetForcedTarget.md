## Verified source facts

- The publisher describes forced-target controls for player-controlled turrets.
- The public source patches `Building_TurretGun.get_CanSetForcedTarget`; it also conditionally targets the Combat Extended turret getter when that package is active. The patch enables the control for player-safe faction turrets when the original getter returns false. This is a source-level description, not a test of every turret type in the selected profile.
- The upstream repository displays an MIT license. This review does not copy its source, textures, icon, or other files into Rimrooms.
- The current Workshop page's removal/compatibility notices and older description make the active installed 1.6 copy a follow-up case; no reason is inferred from Steam's notice.

## Rimrooms integration decision

- **Provisional disposition:** configuration-only; no Rimrooms turret patch or dependency planned. Leave firing and target selection to the selected profile's existing turret behavior.
- Related systems: `RR-GATE`, `RR-THREAT`, `RR-COMPAT`.
- What must remain safe: Rimrooms security and threat counterplay cannot require this targeting button; unsupported turret classes must retain their original behavior.
