# RimWorld mod review: Wololoo - Better Conversion and Recruitment

- Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3108763487
- Row 262; local package `RedMattis.BetterConversion`.
- Local version blank; supports RimWorld 1.4–1.6; local metadata requires Harmony and Ideology and orders after Ideology. Ideology is DLC.
- Reviewed 2026-09-27 using the dated local metadata snapshot for RimWorld 1.6.4871 rev590. No in-game or multiplayer test was run.

## Source facts

The plain Workshop URL returned Steam’s “too many requests” response, but the publisher’s English-language page loaded. It identifies Ideology as required DLC and says prisoners above 35% mood lose certainty instead of gaining it, at the normal gain rate; certainty may appear to move the wrong way before dropping to its proper value. Conversion reduces resistance by 75% or 15, whichever is higher, and will by 50% or 5, whichever is higher. The page shows removed-item and “incompatible with RimWorld” status banners; these are page notices, not reproduced compatibility findings.

**Dependencies and reuse:** The publisher page lists Ideology as required DLC but does not list Harmony as a mod dependency; local metadata does. No license/reuse statement or linked source repository was visible in the accessible description.

No public API or code hook is assumed from this source review. See the publisher/package sources before any future patch work.
