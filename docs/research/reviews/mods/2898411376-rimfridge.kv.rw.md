## Source facts and Rimrooms use

The publisher describes powered refrigerated racks in several sizes, three item stacks per cell, and wall fridges reachable from both sides; adjacent nutrient-paste dispensers can use them as hoppers. Change notes mention an airtightness option affecting gravship oxygen exchange and an `ICompRefrigeratorParent` interface. A user report about LWM Deep Storage's capacity is not reproduced for selected row 122. The page says its package ID conflicts with other RimFridge variants, which are not selected.

**Provisional disposition:** optional refrigeration/storage. Related features: `RR-FAC`, `RR-STA`, `RR-EVD`, `RR-ECO`, `RR-SPACEFLIGHT`, `RR-COMPAT`. Do not treat a two-sided wall fridge as a custody barrier.

## Runtime follow-up

No runtime test was run. Check temperature/power failure, both-sided access, stacks/filters, paste-hopper behavior, selected storage capacity, save/load and selected gravship oxygen behavior. Factory-hopper support must be tested, not assumed.
