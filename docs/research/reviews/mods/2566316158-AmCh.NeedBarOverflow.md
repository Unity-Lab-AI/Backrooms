# RimWorld mod review: Need Bar Overflow

- Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=2566316158
- Row 142; package `AmCh.NeedBarOverflow`; local version 1.4.7; support 1.2–1.6; Harmony required. Local order-after Harmony/Core; no conflict declared.
- Publisher states GPLv3. Page claims DLC support; local metadata order does not prove DLC is required. Reported Alpha Books issue is marked unconfirmed by author.

## Source facts and Rimrooms use

Publisher says needs can exceed 100%, with optional hunger/rest/recreation effects; Hemogen and Psyfocus are unsupported. The page describes patches for RimHUD, Tweaks Galore, Character Editor, and CM Color Coded Mood Bar. It mentions a potential row 75 Do Recreation When Idle interaction; reports remain unverified.

- **Provisional disposition:** optional staff-need behavior; Rimrooms cafeteria, recovery and expedition systems must not rely on overflow.
- **Feature mapping:** `RR-STA; RR-FAC; RR-COMPAT`.
- **Checks:** supported need caps/settings, mechanoid display, saves/removal, then row 75 and Common Sense over a long session; Alpha Books separately if selected.

No issue or interaction was reproduced.
