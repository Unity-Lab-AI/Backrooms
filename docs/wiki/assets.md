# The assets

**Everything listed here is original to this project.** Nothing is copied from another mod, and nothing is extracted from the game.

Where Rimrooms uses one of the game's own pictures or sounds, it names the path and the game provides it while you play — that file is not in this package and is not on this page.

**24 drawings and 4 sound cues, 21580 KB in total.**

This page is generated from the package itself on every build, so it cannot drift from what actually ships.

## How to read the facings column

A building that can be rotated needs a separate drawing per direction. The game mirrors west from east for free; nothing else is free.

**`one frame` means the building does not rotate** — which is deliberate. A rotatable building with one drawing would show a missing-texture square on three sides out of four, and you would only find out after placing it.
