# Multiplayer

**Nothing about multiplayer is promised.**

---

## What there is not

| | |
|---|---|
| **No shared colony** | |
| **No shared map** | |
| **No synchronised research** | |

## What it would be

Each player runs **their own company**, in their own colony, on their own map.

Not one base with several people in it.

## What has been tested

**Nothing.** No multiplayer session has been run.

---

## If you try it anyway

It is not blocked. But treat it as untested: back up your save, and expect the single-player
experience to be the supported one.

Report what happens — see [Links](links.md).
