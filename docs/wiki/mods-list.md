# The mod list

Rimrooms was built alongside **296** mods and expansions. This page says what each one is for, and what changes if you leave it out.

The base game is listed too, for context. It is not counted in that 296.

## Nothing here is required to launch

**Rimrooms declares no mod as a hard dependency and starts on its own.** *Required* below means required for the experience as it was built, never required to run.

Leave out anything tagged Optional and nothing breaks. Rimrooms falls back to what the base game already ships.

| Tag | How many | What it means |
|---|---|---|
| **Required** | 2 | The game itself. |
| **Recommended** | 83 | Built against this. Skipping it loses a part of the intended experience. |
| **Optional** | 192 | Works with it, works without it. |
| **Visual only** | 4 | Changes how things look and nothing else. |
| **Not needed** | 16 | Rimrooms does not interact with it at all. |

## Required (2)

| Mod | What it does here | Without it | Watch for |
|---|---|---|---|
| **Core** | Everything. Every gate is one of Core's own doors, every cue falls back to a Core sound, and every object Rimrooms cannot supply is one Core already ships. | This is the game itself. | Rimrooms targets RimWorld 1.6. |
| **Rimrooms - Async Industries** | This is the mod this list is about. | There is no list. | Declares no hard dependency on anything below, and starts on its own. |
