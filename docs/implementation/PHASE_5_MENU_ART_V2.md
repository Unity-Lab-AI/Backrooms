# Painted Backrooms menu images

**Owner direction:** original Backrooms main-menu backgrounds in RimWorld's illustrated science-fiction style, with the exact mod name and current version beside native top-left version information. These menu images are the approved exception in the [content-reuse policy](../CONTENT_REUSE_POLICY.md).

Two original images were generated with the **built-in image_gen tool** on 2026-09-28. They use no source images, film frames, screenshots or named characters. The first v1 candidates are preserved; these are separate v2 files. Their **full final prompts, hashes, native dimensions and package destinations** are in [menu-art-v2.json](assets/menu-art-v2.json).

| Illustration | Source master | Use |
| --- | --- | --- |
| Facility threshold | [RR_Menu_FacilityThreshold_v2.png](../../assets/source/menu/RR_Menu_FacilityThreshold_v2.png) | Staff preparing at a powered corporate threshold into repeating institutional corridors |
| Field survey | [RR_Menu_FieldSurvey_v2.png](../../assets/source/menu/RR_Menu_FieldSurvey_v2.png) | An expedition studying physical documents among ordinary furniture and unsettling repeated rooms |

The files are copied unchanged into `Mod/Rimrooms - Async Industries/1.6/Textures/UI/Menu/`. They are **1672 × 941**, the tool's actual native output; there was no resizing, cropping or editing, and they are not 4K masters. Both were visually inspected for composition, painted style, lack of baked title/version and a subdued left area. The scenes depict functional roles artistically; they do not promise new in-game item, bench or equipment assets. Native items/buildings continue to supply those roles.

The controller draws `Rimrooms - Async Industries` and the running assembly's version as UI text beside the existing top-left information. Keeping that text separate avoids stale version artwork. The two older v1 candidates remain outside the loadable package. Actual native-menu overlays, supported crops, UI scales, DLC hover transitions and other menu-mod behavior remain owner-launched acceptance work. No game was started to produce or inspect these images.
