# Links

## RimPLC

- Repository on Forgejo: [git.unityailab.com/GFourteen/RimPLC](https://git.unityailab.com/GFourteen/RimPLC)
- Repository on GitHub: [github.com/G-Fourteen/RimPLC](https://github.com/G-Fourteen/RimPLC)
- This wiki: [g-fourteen.github.io/RimPLC](https://g-fourteen.github.io/RimPLC/)

The repository carries the loadable package, the source of both assemblies, the shipped preset,
the JSON schemas under `docs/schema/` and this wiki's source under `docs/wiki/`.

## Rimrooms

RimPLC is a separate mod from **Rimrooms - Async Industries**, the company mod whose automation
file the shipped preset's steps are written for. Each is enabled on its own; neither requires the
other.

- Rimrooms wiki: [g-fourteen.github.io/Rimrooms-AsyncIndustries](https://g-fourteen.github.io/Rimrooms-AsyncIndustries/)
- The automation file the preset's steps name: [Rimrooms -- The interface](https://g-fourteen.github.io/Rimrooms-AsyncIndustries/interface.html#automation-file-optional)
